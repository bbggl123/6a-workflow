# best-practices — 各角色须遵循的范例与反例

本目录沉淀可复用的工程范例。每个文件聚焦一类实践：

## 核心实践文档

- `tool-usage.md` — **v4新增** 工具使用规范（先读后写、精确替换、禁止破坏性操作、命令行纪律、搜索策略）
- `search-citation.md` — **v4新增** 搜索策略与版权引用规范（何时搜、怎么搜、引用长度限制、版权合规）
- `file-operations.md` — **v4新增** 文件操作纪律（目录三层分离、创建/编辑/交付规则、.gitignore规范）
- `memory-system.md` — **v4新增** 记忆系统使用手册（部署、条目格式、同步纪律、上下文恢复）
- `gotchas.md` — **v4.1新增** 模型最易踩的坑（高信号区：记忆当数据库查、可信度应付门控、角色不声明、评委当夸等）
- `prompting.md` — 角色指令与输出 Schema 范例
- `context-engineering.md` — 项目上下文分析清单范例
- `atomization.md` — 原子任务拆分粒度范例（单任务 ≤200 行）
- `credibility-labeling.md` — 可信度四行说明的合格 vs 失真范例
- `pr-ci.md` — PR 描述与 CI 门禁配置范例

> 新增范例时标注来源任务与日期，便于追溯。
